# Shade Match

Luxury beauty shade matcher prototype for finding the closest makeup colors from photos and real beauty inventory.

## Features
- Upload a photo or use a sample shade
- Extract dominant colors from the image
- Match closest shades across beauty categories
- Filter by product type, finish, and price
- Save favorites and browse price-ranked matches
- Luxury neutral UI designed for a polished demo

## Stack
- Next.js
- TypeScript
- Tailwind CSS

## Getting started

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open http://localhost:3000

## Notes
This is a polished prototype with a demo catalog and front-end color extraction logic. It is structured so a real beauty catalog API can be plugged in later without changing the interface.
